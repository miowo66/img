# img — 自用图床

GitHub Pages 托管的个人图床。

- **上传页**：https://miowo66.github.io/img/
- **外链格式**：`https://miowo66.github.io/img/<文件名>`
- 上传页也可本地双击打开（`github-pages-图床.html`），Token 只存本机浏览器。

## 注意

- 仓库根目录必须有 `.nojekyll`（已添加）。否则 Pages 的 Jekyll 构建会**忽略以 `_` 或 `.` 开头的文件**，这些文件访问会 404。
- 新上传的文件要等 Pages 重新构建（约 30–90 秒）才能通过 `github.io` 访问。
- 免费额度：单文件 ≤ 100 MB，站点建议 ≤ 1 GB。
