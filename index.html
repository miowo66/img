📖 使用说明（点开）
  1. 第一次使用：点右上角 🔑 Token 设置，粘贴你的 GitHub classic token（勾 repo），点「保存 Token」。保存时会自动向 GitHub 校验一次，通过后下次打开不用重填。
  2. 上传：点上传区选文件，或直接把图片 / 音频拖进去，支持一次多选。上传进度和成功 / 失败状态会显示在上传队列里。
  3. 图库按上传时间倒序排列，最新传的在最前面，卡片上会显示相对时间（如「3 分钟前」）。这个时间是从提交历史倒推出来的——GitHub 的文件接口本身不返回时间戳，所以第一次加载会多花一两秒，之后缓存在本地。
  4. 图库：每张卡片可以 复制 外链（https://用户名.github.io/仓库名/文件名 格式）、打开 原文件、删除（调用 GitHub API DELETE，用文件 sha 定位）。
  5. 换用户名 / 仓库：打开本文件，改最上面 CONFIG 里的 owner、repo、branch 即可，全站只认这一处配置。
  6. 想把页面本身也放到网上：把这个文件改名为 index.html 提交到仓库根目录，之后访问 https://用户名.github.io/仓库名/ 就能直接用（手机也能开）。
⏳ 刚上传的文件，github.io 外链要等 Pages 重新构建（一般 30–90 秒，偶尔几分钟）才会生效。 卡片缩略图会先用本地预览顶上，外链暂时 404 是正常的，等一会儿点「🔄 刷新图库」即可。
